## 4Ws Structure

- **Who:** All users — from Standard Users (Sadhaaran Upayogakarta) to Power Users (Shakti Upayogakarta).
- **What:** Comprehensive categorized database of Windows keyboard shortcuts (Yantrik Laghumarg).
- **Where:** Windows 10/11 desktop, File Explorer, browsers, and applications.
- **Why:** Keyboard shortcuts dramatically accelerate workflow, reduce mouse dependency, and improve productivity — especially for administrators managing multiple systems simultaneously.

## Power User Tips

### Create Custom Keyboard Shortcuts

```powershell
# Create a shortcut for elevated PowerShell
$shortcut = (New-Object -ComObject WScript.Shell).CreateShortcut("$env:USERPROFILE\Desktop\AdminPowershell.lnk")
$shortcut.TargetPath = "C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe"
$shortcut.Arguments = "-NoExit -Command Start-Process PowerShell -Verb RunAs"
$shortcut.Hotkey = "CTRL+SHIFT+P"
$shortcut.Save()
```
